# Resume task delivery qualification

ENG-719 / R-1137 implements part 1 of the operator's combined recommendation,
on top of ENG-801's original-path restoration and completion identity.

New requests arm the supervisor watcher with a proposed unique native name,
then pass the generated task as a literal argument through the existing `ai`
launch seam. Codex receives `resume UUID -C WORKTREE -- TASK`; Claude receives
`--resume UUID -- TASK` in the restored working directory. Existing native
admission, ownership, source, STOP/HOLD and pending-request digest guards apply.
There is one native attempt, with no pane prompt, replacement or resend.

Before launch the dispatcher pins the known transcript file identity and append
offset inside the configured launch home. It observes the actual saved native
ID from transcript metadata. Binding requires an exact new user task and fresh
folder context, plus the original native PID/birth, worker receipt and bounded
60-second delivery window. A native session ID at launch is diagnostic until
that qualification. The observed transcript ID must agree with any Herdr ID;
a null Herdr ID can qualify only through the fresh transcript evidence. Old
transcript contents and pane cwd alone cannot qualify a resume. The journal
retains the observed range, task hash and timestamp. The record writer rejects
a resume binding without its qualification evidence; exact proposals remain
idempotent after lost replies. Existing saved requests and watchers retain
their original protocol.

Focused selection: the existing runner runs the new resume-delivery tests,
completion-resume lifecycle tests, session-bind tests, direct-report-routing
and fresh correction-launch tests once through lane check on committed source.
The run's archived gate/validation receipts record actual outcomes, Node version
and TAP totals. No baseline, full tier or release suite is selected.

Native adapters exercise real record, Git, closeout, reopen and dispatch
orchestration for both harnesses, from retained and integrated branches, with
present and null native session IDs. No live model conversation is started.
The retired BCH R-3496 attempt is retained unchanged and UNKNOWN. Live resume
acceptance (including AGENTS.md loading), live supervisor delivery and full
release coverage remain with the release coordinator; offline evidence does
not claim those checks passed. No outside-Brain source, service, pin, saved job
or long-lived runtime is edited.
