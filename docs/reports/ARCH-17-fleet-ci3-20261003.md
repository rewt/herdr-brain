The shared inventory copies complete runtime directories instead of selected
JavaScript files. New modules within those directories therefore enter every
copy automatically. It includes the lane review template and the discovery

project state. Stable entry snapshots retain their content hashing, read-only
file modes, staged publication and existing snapshot verification. Console and
MCP copies include their package manifests and lockfiles without dependency
caches. Older products can still lack newer runtime directories.
