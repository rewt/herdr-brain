learnings:
  - Herdr 0.8.2 tab.create with focus=false does not update a background workspace's active_tab_id.

  - Socket tab.focus accepts only tab_id; an extra focus=false parameter is ignored and global workspace, tab and pane focus all move.
  - lane open already creates and exposes the default shell before the separate dispatch invocation; an idle shell observed at dispatch does not prove the operator never used it.
  - Current dispatch supplies route environment and MONITOR_ENTRY_BYPASS at tab creation; worktree.open and agent.start have no environment parameter for initial-pane reuse.
