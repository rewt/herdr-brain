The Major finding is fixed by `lane open --git-only`, used by the standard
dispatch module and documented for manual open-then-dispatch callers. It keeps
the existing Git ownership and path checks but performs no Herdr calls. Dispatch
then obtains its own native `already_open=false` receipt. The regression installs
fake Herdr before opening the lane and confirms one selected initial agent tab,
no `tab create`, and no focus or close operation. Plain interactive `lane open`
continues to expose its shell, which dispatch preserves as existing operator work.

The Moderate and Minor findings are fixed together. Private source and verifier
files contain literal quoted assignments and expected values. The typed command
contains only paths, starts with a space, suppresses source diagnostics, and
deletes both files. The source disables tracing before assignments. A child shell
checks the effective exported environment, including command-line overrides and
the entry bypass, and prints a nonce absent from the typed input. Dispatch waits
for that exact output line before agent start. Missing or incorrect confirmation
fails with the initial tab retained and no agent or brief started. Node cleanup
also removes the directory on every normal return or failure.
