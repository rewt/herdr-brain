and descendants remain in the runner's owned process group. The native stand-in
still refuses inference. The shared fixture policy and strict native transport
leak guard are unchanged.

foreign-root/identity refusals, and the refusal after an owned pane moves to a
foreign cwd. For each refused command it now checks that no native call begins
with those arguments, including calls with appended creation options. Unrelated
lifecycle reads cannot affect this assertion. Receipt-owned producer teardown
is retained.
