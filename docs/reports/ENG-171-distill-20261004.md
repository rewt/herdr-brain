Implemented `brain digest --org DIR [--json] [--limit N] [--max-chars N]`
and `--ack PASS_ID`. Default output is bounded to 40 signals and 24,000 JSON
characters, with hard ceilings of 100 and 64,000. Signals include event references,
run/item references when available, applicability paths and review verdicts.
Long excerpts are explicitly marked so the distiller reads their originals.

Brain stores only the cursor and latest pending digest under its own state,
keyed by the canonical record-directory identity. Symlink aliases share the
cursor; different records remain separate. Prefix hashes detect record rewrites
and truncation. Malformed state, torn event writes, duplicate sequences and
concurrent cursor access refuse without advancing. Acknowledgement is safe to
retry, and events appended during a routed pass remain for its next page.

Modern settle notes can retain verified review findings from their linked
receipt, provided its decision, run, item, record, report hash and review-text
hash agree. Missing or changed evidence falls back to the actual recorded note
with an explicit instruction to inspect the source. Failure notes are literal
candidates to investigate; neither a bare exit code nor round count invents a
cause. No record events are written by this command.

The short distill procedure requires one or two actionable scoped sentences,
two independent signals or one confirmed gate failure with a supporting cause,
and only `record lesson add`. Supervisor review activates or rejects proposals
before acknowledgement. It documents normal routed dispatch and an on-demand
release-cycle pass, with no schedule installed. Code/default changes still use
the existing review, train and release gate.

The selected record already contains supervisor-proposed and activated seeds
L-1 through L-7 (proposal events 2744–2750, activation events 2751–2757). This
run did not duplicate or activate those lessons. Private-memory seeds go through
the same shared-record evidence bar in the documented procedure.

Tests were written before implementation. The initial red invocation failed
