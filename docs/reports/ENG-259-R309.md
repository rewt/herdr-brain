Supervisor and chat launches resolve HERDR_SOCKET_PATH (or the default home
control socket), verify its type and current-user ownership, and perform a
bounded connection probe without sending a Herdr request. Both an endpoint
named herdr-client.sock and aliases resolving to it are refused. Failed probes
name the socket and connection reason before the native session starts.

Claude receives the resolved endpoint in its CLI-scope allowUnixSockets array.
Both coordinating roles gain scoped Edit and shell-write grants for the selected
project's worktree root and keep canonical coordination state writable. Workers
and reviewers retain sibling-lane and coordination-receipt write restrictions,
including the native file-tool hook. Peer project write exclusions remain.
The bridge warning names the canonical .claude/settings.local.json file and
grant-herdr-socket.mjs --remove; Monitor never edits that file. Existing chats and
adopted prototypes need a restart to receive the new role and grants.

Codex uses a fresh coordinator permission profile and its built-in network
enforcement feature. A second connection probe runs inside the generated native
profile, including managed requirements when supported. Unsupported builds,
explicit conflicting CLI selectors, inherited legacy sandbox selectors and
native probe failures refuse handover with a reason. Generated worker profiles
disable direct network access because the previous network.enabled=true allowed
arbitrary control-socket connections. Deliberate inherited worker policies still
receive the existing warning and remain native operator choices.

Validation was offline and model-free. The six affected test files produced
155 passes with five optional native probes skipped. The new native role suite
used Claude 2.1.293's actual bundled macOS wrapper and Codex 0.160.0's sandbox:
all nine tests passed. Workers and reviewers were denied fake control sockets
and lane-root mkdir; supervisors and chats could connect through resolved paths
and aliases and create lanes. Every role remained denied a sibling socket and
ungranted file writes. Two additional native worker regression cases passed,
covering peer writes, protected receipts and control-socket aliases.

The official native profile contract is documented at
https://learn.chatgpt.com/docs/permissions. Linux Claude path-scoped Unix socket
enforcement remains unsupported by the native runtime; this run proves the
macOS boundary, not Linux confinement.

The final action after committing this report is lane check with the same six
focused files and both native socket probes enabled. Its .lane/gate.json receipt
and GATE output identify the final report commit. No full baseline, promotion,
release or live acceptance suite was run; no lane was promoted or pushed.
