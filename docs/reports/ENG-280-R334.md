The correction addresses the Moderate finding in
`docs/reviews/waiting-rank/d48b844-r1.md`. The modern model now exposes `aged`
separately from future-stage `parked`, deferred `later`, and current `needs`.
The Waiting on you screen has one clickable parked count with
`record today --parked`; opening it lists the aged questions, which can still
be opened and answered. The overview and Control summary also show the count
and command. The overview includes that section when only aged questions
remain. Its single-line hint fits the minimum 80-column frame.

`waitingImpactIndex` makes one pass over links and unresolved items, indexing
current open/waiting runs, report blockers, and each eligible target's latest
explicit plan. `todayJson` constructs that index once and shares it with all
question lookups, including parked questions. Each lookup traverses only the
question's dependent subgraph and looks up named runs and plan counts; it
does not scan items or notes. Counts still deduplicate dependency diamonds,
linked/named runs and repeated question mentions within a plan step. Resolved
work, superseded/abandoned reports, completed plan steps, and a question's own
plans remain excluded. Reads without open questions skip building the index.

The new index test instruments every eligible target's notes: each is read
once during indexing, and repeated lookups for two questions add zero reads.
It also verifies exact ID matching, repeated mentions, shared plan steps and
self-reference exclusion. Existing today tests retain coverage of dependency
deduplication, run supersession, explicit plan boundaries and age parking.
Modern-console coverage asserts the model's separate counts, reachable aged
rows, one parked hint on the waiting frame, singular/plural overview hints,
the complete command at 80 columns, and the aged-only overview. Both classic
model/waiting/frame tests and modern model/frame tests ran offline.
