Implemented only the requested project configuration and installed launch path;
no live project config, machine install, pane or service was changed.

The wrapper accepts pane read with optional positive --lines, pane/tab list with
optional workspace, and pane wait-output with exactly one literal/regex matcher
and allowlisted source, lines and timeout options. It rejects mutations, global
options, duplicate or malformed flags, control characters and shell injection.
It reconstructs argv and spawns the installation-pinned real executable without
a shell. The launcher clears interpreter preload variables. Generated sandbox
and Edit rules protect the entry bin, wrapper code, Herdr and Node from writes.

Read launch refuses inherited sandbox disablement, all-socket/foreign-socket
grants and additional exclusions. This includes ENG-259's old local bridge.
Switching modes requires closing the old chat tab and opening a fresh chat;
read mode never adopts an unverified prototype. The launch policy states the
mode and prints the exact absolute wrapper path. Native Claude requires the
executable path unquoted; arguments can be quoted normally.
