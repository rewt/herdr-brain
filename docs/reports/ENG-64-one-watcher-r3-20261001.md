## Refusal and retry semantics

The refusal is a deliberate boundary, not a silent loss. `open-session` holds its short
check-and-start lock only while deciding whether it may launch. If a `settle-*` or `exec-*` agent
is already working, it removes the lock, raises a Herdr notification, names the busy session and
exits nonzero. It does not occupy the supervisor waiting for work of unknown duration.

The long-running supervisor still owns the final `[org-report]` prompt. It must not mark that
prompt handled after the refusal. It blocks specifically on the named agent reaching `idle`,
`done` or `blocked`, then retries `supervisor/settle.sh R-n`. The retry either opens the fresh
session or reports that the run is already recorded. This preserves serialization without adding
a second watcher or an implicit background queue.

## Watch idle grace

`--idle-grace SECONDS` defaults to zero, so existing Herdr Monitor behavior is unchanged. Once a
worker has been observed working, the option delays only an idle/done no-report notice. A report
filesystem event or a resumed worker wakes the same blocking wait immediately; blocked, gone and
invalid-report handling is unchanged. The bch-cloak plan passes `--idle-grace 900`, matching its
current transient-idle accommodation.
