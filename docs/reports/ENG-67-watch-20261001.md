## Result

`watch/watch.mjs` follows one recorded run. It reads the worker and report path from `org show`,
uses Herdr's blocking `agent wait`, and watches the report directory with `fs.watch`. A report
event is rechecked across the watch-install race, so a report that lands between inspection and
subscription is not missed. A one-hour timer (configurable with `--long-after`) produces one
long-running notice rather than waking periodically.

When the report is complete, the watcher runs `org check`, parses the same report envelope as the
core, and prompts `supervisor-herdr` with an `[org-report]` line containing the run, item, outcome,
headline, `check=pass`, and path. Invalid report, no report, blocked, long-running and Herdr-
unavailable conditions have separate prefixes. Delivery retries five times over at most forty
seconds before falling back to an operator notification and leaving the watcher tab visible.

The watcher never calls a model, writes `events.jsonl`, runs `org ingest` or `org sync`, or closes
the worker's tab. A per-run lock prevents duplicate watchers. With `--spawn`, it creates a visible
`watch R-n` tab in the caller's Herdr workspace and closes that tab only after successful delivery.

## Arm the next run

After `org start`, lane dispatch, and `org set R-n agent=<name> pane=<id>`, run this from the
supervisor's Herdr pane:

```sh
node /Users/rewt/development/rewt/.worktrees/herdr-brain/lane-watch/watch/watch.mjs R-n \
  --org /Users/rewt/development/rewt/.org \
  --to supervisor-herdr \
  --spawn
```

`--spawn` uses the caller's `HERDR_WORKSPACE_ID`, opens the watcher tab without focus, and returns.
The supervisor does not run a shell loop or spend a turn polling.

## Replacement boundary

This is the replacement for bch-cloak's `notify-watch.sh` when Phase 3 reaches a quiet cutover.
It builds on the blocking wait and prompt delivery proven by `notify-watch.sh` and
`contrib/settle-watch.mjs`. It does not replace Brain `watch`'s operator queue or
`settle-watch.mjs`'s model-session handoff today. ENG-64 already owns retiring or narrowing those
remaining duplicates, so this report creates no duplicate proposal.
