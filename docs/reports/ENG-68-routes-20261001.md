## Result

`lanes/routes.mjs` is the single validator and resolver. It preserves the kit file's
complete object, resolves defaults and named routes, appends `always_args`, supports
the current argument-encoded effort during migration, and resolves selection policy
by task class and pool.

`lane dispatch <topic> --route <name>` now records route, harness, model, and effort
in its display-only session record and passes the same resolved values to Herdr.
`record start <ID> --route <name>` discovers the canonical checkout's parent and
repository lane config, records the same route values, and refuses copied metadata
flags. An explicit `--route-config` supports a standalone routing file. The record
continues to treat every value as opaque run metadata.

Supervisor note (settlement): the change to `contrib/settle-watch.mjs` was reverted before
promotion. bch-cloak's `scripts/lane/launch-supervisor.mjs` calls that file by absolute path in
this checkout with `--model` and `--effort`, which the new resolver refused, so main moving would
have broken a bch-cloak command. It moves onto `lanes/routes.mjs` with ENG-64's release-gated
switch.
