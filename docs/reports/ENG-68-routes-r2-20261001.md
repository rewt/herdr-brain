## Finding-by-finding resolution

All changes below are in implementation commit
`Fix routes review findings and isolate launch argument handling` on `lane/routes`.

1. **Core harness branching** — commit cited above. `bin/org.mjs` continues to call
   `resolveRoute`, which now copies only declared kind, model and effort. Only
   lane calls `resolveLaunchRoute` for native argument inference and launch
   plumbing. The flow test records a legacy Codex route with no inferred effort;
   lane tests verify that the same legacy config retains its launch effort.
   `docs/config/herdr-brain-effort.patch` adds explicit effort to dispatch and
   all seven legacy Codex routes, removing the corresponding raw effort arguments.
   Applying it to a scratch copy preserved kind/model/effort/environment for
   dispatch and all 15 shared routes and aligned record and launch metadata.
   **Boundary:** the shared file was not edited. Applying this patch remains
   ENG-69; until then legacy run records omit undeclared effort.

2. **Named-route argument collisions** — commit cited above. Ported the kit's
   reserved-argument checks for Codex model/profile flags and model,
   model_reasoning_effort and profile config expressions, plus Claude
   model/effort/plugin options. Named-route caller overrides are rejected in
   separate, attached, equal, whitespace and quoted-key forms. Lane tests cover
   legacy and declared Codex routes and Claude routes and assert zero Herdr calls
   on refusal. Nonreserved argument replacement keeps a named route's configured
   effort; unrouted legacy argument overrides remain supported. Trusted configured
   launch arguments retain compatibility.

3. **Incorrect round-one report** — commit cited above. Corrected its summary and
   settle-watcher learning to say the watcher retains its prior implementation
   until ENG-64. The round-one implementation is cited by its subject,
   `Add shared route resolution`, so later rebases do not stale the reference.
   Added an explicit round-two correction documenting the new declared-effort
   boundary. No historical record report was re-ingested.

4. **Duplicate always_args options** — commit cited above. The supplied-option
   check includes model and effort options that dispatch will emit, including
   Codex aliases. Actual fake-Herdr launch tests assert exactly one canonical
   model and effort for both Codex and Claude while unrelated defaults survive;
   a resolver test covers Codex short/long aliases.

5. **Record-root route discovery** — commit cited above. Outside Git, discovery
   reads the nearest .lane.json in the working directory or its ancestors.
   A flow test starts routed runs from a non-Git record root and its .org
   subdirectory. Git callers retain canonical checkout discovery. README.md
   documents both behaviors.

6. **Missing integration coverage** — commit cited above. Added a linked-worktree
   flow test that resolves both parent defaults/inherited routes and canonical
   repository overrides. A conflicting physical-parent config and repository
   config written after worktree creation distinguish canonical discovery from
   reading the linked copy. Added --route-config without --route refusal and
   lane dispatch --route with --kind/--model refusal tests.
