The reviewed Moderate is addressed. The PTY command and its blocked grandchild handle SIGHUP and run outside the live suite group. Regressions inspect their actual groups, then require the command group and native owner group to be empty after command timeout, SIGTERM, SIGKILL, the suite watchdog, and ordinary completion. An additional interactive shell launches a background job in a different group inside the terminal session; cancellation clears that group too. An unrelated sentinel survives each cleanup.

The native owner remains alive through cleanup, freezes session producers, signals freshly confirmed members with kernel process identities, and reports failed cleanup. It retains TTY descriptors, literal arguments, output and the command exit status. Its deadline and cleanup are independent of the Node event loop and the suite process group. After transport death, cleanup can continue for up to three seconds; regressions wait for confirmed disappearance before directory removal. Node descendants retain the containment preload. Native commands that deliberately create another session still require their own lifetime owner.

The nested release suite now uses the existing runner rather than a synchronous call whose nominal 60-second timeout was clamped to 15 seconds. Only that fixed asynchronous runner can request a child bound up to 55 seconds. Its file bound is 45 seconds and its suite watchdog 50 seconds. A regression runs for 15.5 seconds and proves an ordinary command cannot request the larger bound. Plugin fixture teardown uses the shared birth-identity child helper and awaits all fixture children before removing directories.

All execution was offline on macOS and made no model calls. Linux argument quoting is covered; the new Linux pidfd cleanup was not independently executed. The initial restricted baseline could not use ps, so approved offline execution supplied the actual validations. The main rebase retained the new supervisor tests, settled watcher shutdown assertions and scratch-removal retries, and supervisor-entry assertions in the plugin tests.
