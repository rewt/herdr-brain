Adopted control center and transport · R-446 · 16 October 2026

A standard session platform and one fleet conversation

Brain is the standalone control plane; Herdr is the required runtime. An optional thin Herdr plugin opens chat, logs and status. The core never depends on that front door.

Manifests create standard workspace tabs and preserve warm review workers. The model-free logging service routes decisions directly, control kinds to rules, and remaining operational traffic to a project triage session beside the logs viewer. All model work runs in Herdr sessions on the subscription.

Read the evidence and adopted plan. Figures 01–02 retain the 15 October observations; figures 03–11 describe the adopted design. Some inspection and shadow-capture slices have since landed on main. Figures 12–14 apply the 16 October operator decisions: an own identity, owner-published summaries first, relay first and one swappable transport adapter. Native setup and transport implementation remain future work; the pilot timing/workspace is a recommended default. Eligible context resets close and respawn from a manifest and handoff; warm review workers stay intact.

Adopted design: the reconcile loop

Read authoritative evidence, compare desired and observed state, then perform at most one authorized action. Declared batch-boundary rotation never overrides an open review chain.

Loading diagram… The source below is always available.

flowchart TD
  Wake[Manifest change, service event or bounded timer]
  Lock[One canonical project controller lease]
  Desired[Read adopted spec, frozen route and generation]
  Facts[Read record fold, jobs, queue, holds and launch receipts]
  Observe[Herdr snapshot plus exact agent observations]
  Compare{Desired versus observed}
  Standard{Protected standard slot or parked review chain?}
  Keep[KEEP occupant; repair observations only]
  Safe{Authorized transition, fresh evidence, no hold and no reset of an open review chain?}
  Action[One journaled action through existing adapters]
  Result{Receipt and observed identity agree?}
  Status[Write disposable status and structured event]
  Ambiguous[Hold; no blind retry, reset or second occupant]
  Wake --> Lock --> Desired --> Facts --> Observe --> Compare
  Compare -->|already matched| Status
  Compare -->|unrequested reset or automatic retirement considered| Standard
  Standard -->|yes| Keep --> Status

  Safe -->|no| Ambiguous --> Status
  Safe -->|yes| Action --> Result

  Result -->|no| Ambiguous
  Status --> Release[Release lease and wait]
  Release -.-> Wake
