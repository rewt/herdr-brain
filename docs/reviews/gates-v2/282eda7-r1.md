- [Major] promote/promote.mjs:879 - Declaration detection runs before the caller identity fence. In config-home mode, readDeclared audits with the target checkout as cwd, so an unaudited declaration edit or pending config write can append or recover target record events before a foreign caller is rejected. This violates refusal before effects; Fix: detect declared mode through a side-effect-free reader, enforce caller/project identity, then perform audited resolution, and add a foreign-caller witness that preserves target record bytes.
- [Major] promote/promote.mjs:65 - Completed results with pending cleanup are omitted from declared-work detection, and cleanup continuations never compare their captured execution\_identity. After a declaration rollback, a foreign --repo caller can reach retirement and lane closure for a saved v2 job; a changed identity root also escapes the captured binding check; Fix: include unfinished cleanup in declared-work detection and fence each cleanup or retry against its saved identity before effects, with foreign-caller and changed-root regressions.
- [Moderate] promote/declared-gates.mjs:128 - The outer planning and executor watchdogs enforce the idle limit on inherited stdout and stderr, while leaf command output is redirected into private step logs. A gate or preparation that emits continuously for longer than the idle allowance is therefore killed as idle by the outer watchdog; Fix: propagate actual leaf output activity to the outer watchdog or disable only its redundant idle timer while retaining leaf idle limits and the attempt wall deadline, and add streaming-output and silent-command controls.
- [Moderate] promote/declared-planner.mjs:26 - The bounded planner/probe wrapper discards all buffered stdout on nonzero exit or signal and converts a child signal into numeric exit 1. Failure receipts consequently lose emitted stdout and the original signal, contrary to the required red-attempt evidence; Fix: preserve bounded stdout independently of success and propagate or explicitly retain the child's original exit and signal, with failing-output and signaled-planner/probe witnesses.
- [Moderate] supervisor/supervisor.mjs:247 - Saved typed requirements are rebound against the current declaration before the supervisor inspects the acknowledged queue outcome. If an integrated lane changes or removes a required gate definition, promote --retry throws before reaching completion recovery, even though no gate execution remains; Fix: recover terminal acknowledged outcomes using their captured requirements and identity before current-policy binding, apply current admission only to unfinished execution, and add a declaration-changing integrated completion-retry witness.
- [Moderate] promote/test/declared-train.test.mjs:94 - The acceptance map cites this test as a damaged-integration-log recovery witness, but its body only rejects an unfinished pending job after a declaration change. The test advertised for unstable paths likewise changes no input during execution, so those negative acceptance claims have no supplied witness; Fix: add actual completed-log corruption recovery and during-command declared-input mutation controls, assert refusal or absence of a reusable source as appropriate, and correct the witness map.
