## Findings
- [Major] lib/lane-removal.mjs:396 - Path selection hides native observation errors before the parser can reject them. When a visible same-user process has a cwd or descriptor-inventory read error, Apple's lsof can discard its error record because it has no matching path or link count. Output containing only the valid caller cwd, empty stderr and exit 1 is then accepted as complete, allowing scratch removal despite an unreadable process. The injected error-record tests do not cover errors suppressed by native selection; Fix: require an independent user-scoped completeness observation that retains native errors before accepting bounded results, keep scratch on any incomplete observation, and add a regression where the native selector omits the unreadable process.
