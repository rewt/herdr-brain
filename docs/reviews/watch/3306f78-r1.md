- [Major] watch/watch.mjs:281 - sendOnce dedupes on lastNotice but lastNotice is never cleared when the worker is next seen working, so a second stop without a report (worker goes idle with no report, is nudged, works again, goes idle again with no report) produces an identical message that is silently suppressed; contrib/settle-watch.mjs resets its notified marker on working and this port dropped that reset, which reintroduces the silence the brief forbids; Fix: set lastNotice to undefined whenever state is working or unknown at the top of the loop, and add a test for idle, working, idle without a report delivering two notices
