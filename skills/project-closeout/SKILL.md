# Hand back and close through the existing line

Read the assigned project's AGENTS.md, run record and current lifecycle contract.
Use its actual source, native identity, claim and owning service. This procedure
does not authorize a worker to invoke supervisor cycle mutations, remove another
identity's files, replace an UNKNOWN attempt or start a cleanup service.

Preserve the finished report, immutable landed base/head, producer evidence and
any held/unlanded branch before ending the worker. Report ingestion supplies the
existing close signal; retain its watcher and completion recipient. Do not keep a
worker open waiting for review. Reviews and corrections start fresh from the record
and may resume a saved session through its recorded ID.

The existing authorized lifecycle owner closes the session and removes the
worktree folder in the same step after report ingestion. Delete the branch only
if its exact tip is already on main; otherwise retain it for a later fix. Keep
the folder if it contains unsaved changes. A completed report is not permission
to discard unique source or break a returning callback: retain the durable
successor/evidence and original pending effects through the project's current
guarded handoff.

Fresh native identity, claim generation, actual Git common directory/worktree,
source/head, ownership, STOP/HOLD, active resource users and recoverable archives
remain checks at the mutation. Display metadata, a chat ID, elapsed age or an
idle-looking pane cannot substitute. Use only the current supported project
lifecycle entry; do not hand-roll session, folder, branch or process removal.

If a closeout-proof hold is active, leave its paths, service, measurement and
candidate untouched. Only its recorded owner can authorize the next integration
step within the governing instructions. Preserve native refusals and unknown
results with the original attempt and send actual exceptions to the PROJECT
SUPERVISOR. Continue independent work; never retry through another executor.

Record the actual session/folder/branch/resource results or the precise retained
condition through the owning record. A request submitted to the line is pending,
not proof that cleanup ran. Do not synthesize a closeout receipt, amend immutable
evidence or reset the running proof to make completion appear successful.
